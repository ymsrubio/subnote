# Svelte 5 + SvelteKit instead of React

The author already knows React and Next.js, but Subnote is partly a learning project, so the frontend is deliberately Svelte 5 with SvelteKit. Svelte was picked over SolidJS for its built-in transitions, springs and tweens, which serve the page-turn, gesture and motion goals, and for its wider ecosystem of PWA and sync libraries.
